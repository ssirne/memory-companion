# Memory Companion

Memory Companion is a web app designed to bridge the communication gap between senior care home residents, their families, and care staff. 

While family members know a senior's personal stories, interests, and favorite memories, caregivers at senior care homes don't always have easy access to this background info. Memory Companion gives families a place to upload key milestones, stories, and personal preferences, which are summarized into quick profiles for staff. It also includes an AI prompt generator to give caregivers personalized conversation starters for their daily shifts.

## Features

- Family Story Submissions: Family members can add stories, background details, and personal preferences to a resident's profile.
- Caregiver Summaries: Quickly displays essential details about a resident so staff can get up to speed fast.
- AI Conversation Starters: Generates custom questions and topics based on the resident's profile to help staff initiate engaging chats.

## Built With

- JavaScript
- Vite
- HTML / CSS

## Local Setup

1. Clone the repository:
   git clone https://github.com/YOUR-USERNAME/memory-companion.git
   cd memory-companion

2. Install dependencies:
   npm install

3. Set up environment variables:
   Create a .env file in the main folder and add your API key:
   VITE_AI_API_KEY=your_key_here

4. Start the app:
   npm run dev

   Then open http://localhost:5173 in your browser.
